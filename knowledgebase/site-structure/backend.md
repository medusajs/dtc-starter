# Backend Structure

## Overview
- **Framework**: Medusa v2.20.1 (`@medusajs/medusa`)
- **Runtime**: Node.js + Express
- **Database**: PostgreSQL 18.6 (MikroORM)
- **Package Manager**: pnpm 11.22.0
- **Location**: `apps/backend/`
- **Package name**: `@dtc/backend` v0.0.1
- **Engine**: Node ^20.19.0 || >=22.12.0

This is a stock upstream install generated by `create-medusa-app@latest` with `--with-nextjs-starter`. No custom modules, plugins, or business logic have been added.

## medusa-config.ts

```ts
import { loadEnv, defineConfig } from '@medusajs/framework/utils'

loadEnv(process.env.NODE_ENV || 'development', process.cwd())

module.exports = defineConfig({
  projectConfig: {
    databaseUrl: process.env.DATABASE_URL,
    http: {
      storeCors: process.env.STORE_CORS!,
      adminCors: process.env.ADMIN_CORS!,
      authCors: process.env.AUTH_CORS!,
      jwtSecret: process.env.JWT_SECRET,
      cookieSecret: process.env.COOKIE_SECRET,
    }
  }
})
```

Only `projectConfig` is defined. No `modules`, `plugins`, or custom workflows registered.

## API Routes

### Convention
- File-based routing under `src/api/`
- Route handlers named `route.ts`
- HTTP methods exported as named functions: `GET`, `POST`, `PUT`, `PATCH`, `DELETE`, `OPTIONS`, `HEAD`
- Path parameters use `[param]` directory names
- Medusa container accessed via `req.scope.resolve(...)`

### Existing Routes (scaffold)

```ts
// src/api/store/custom/route.ts
import { MedusaRequest, MedusaResponse } from "@medusajs/framework/http"

  res.sendStatus(200);
```

## Workflows
**Status**: Empty — only `src/workflows/README.md` exists.

Convention: `createStep` + `createWorkflow` from `@medusajs/framework/workflows-sdk`. Steps return `StepResponse`, workflows return `WorkflowResponse`. Workflows executed via `workflow(req.scope).run({ input: ... })`. Business logic belongs in workflows, not route handlers.

## Subscribers
**Status**: Empty — only `src/subscribers/README.md` exists.

Convention: export default async handler; export `config: SubscriberConfig` with `event` string. Handler receives `{ event, container }` or typed `SubscriberArgs`.

```ts
export async function orderPlaced({ event, container }: SubscriberArgs) { /* ... */ }
export const config: SubscriberConfig = { event: "order.placed" }
```

## Admin Customizations
**Status**: Minimal scaffolding only.

- `src/admin/i18n/index.ts` — empty `export default {}`
- `src/admin/vite-env.d.ts` — Vite type declarations
- `src/admin/tsconfig.json` — TS config for admin extensions (ES2020, bundler mode, React JSX)
- No widgets, UI routes, or admin pages defined.

Convention: widgets are React components exported with `defineWidgetConfig` from `@medusajs/admin-sdk`, attached to a `zone` (e.g., `"product.details.after"`). Admin extensions are hot-reloaded in development.

## Module Links
**Status**: Empty — only `src/links/README.md` exists.

Convention: `defineLink` from `@medusajs/framework/utils`. Links synced to DB via `pnpm exec medusa db:sync-links`.

```ts
export default defineLink(

  ProductModule.linkable.productVariant
)
```

## Environment Variables

The backend requires these keys in `apps/backend/.env`:

| Key | Purpose |
|---|---|
| `DATABASE_URL` | PostgreSQL connection |
| `JWT_SECRET` | JWT signing secret |
| `COOKIE_SECRET` | Cookie signing secret |
| `STORE_CORS` | Allowed origins for store API |
| `ADMIN_CORS` | Allowed origins for admin API |
| `AUTH_CORS` | Allowed origins for auth API |
| `REDIS_URL` | Redis connection for event bus (optional) |
| `MEDUSA_ADMIN_ONBOARDING_TYPE` | Admin onboarding type |
| `AUTH_MFA_ENCRYPTION_KEY` | MFA encryption key |
| `MEDUSA_ADMIN_ONBOARDING_NEXTJS_DIRECTORY` | Path to Next.js storefront |

For actual values in this installation, see `context.md`.

`apps/backend/.env.template` ships with a subset of these keys. The 3 keys present in `.env` but missing from the template are `MEDUSA_ADMIN_ONBOARDING_TYPE`, `AUTH_MFA_ENCRYPTION_KEY`, and `MEDUSA_ADMIN_ONBOARDING_NEXTJS_DIRECTORY` (added by the CLI at install time).

`apps/storefront/.env.local` (no `.env.template` in this install) sets the publishable API key and backend URL. For actual values, see `context.md`.

## Code Style

From `AGENTS.md` (repo root) and `apps/backend/.medusa/...` defaults:
- **No semicolons**, double quotes, 2-space indent (existing `route.ts` files do use semicolons, which is upstream scaffold inconsistency)
- File names: kebab-case
- Types/classes: PascalCase
- Functions/variables: camelCase
- DB columns: snake_case
- No emojis in code/comments/commits
- Must satisfy `@medusajs/eslint-plugin` recommended config
